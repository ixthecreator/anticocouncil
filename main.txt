                           系统功能完整说明

【系统概述】
“安提柯议会”是一款专为组织、编辑部或社团设计的数字化会议与决议管理平台。系统采用极简的古典排版美学（衬线字体、大量的留白与模块化卡片），并结合现代化的工作流，支持议题的完整生命周期管理。

【核心功能模块】

1. 全局数据存储与多端同步 (Storage & Sync)
   - 本地缓存模式 (Local Storage)：开箱即用，数据安全存储于浏览器。
   - GitHub 同步模式 (GitHub Repo/Gist)：支持将数据绑定至 GitHub 仓库或 Gist，实现跨设备云端版本控制。
   - Spring Boot 后端模式 (Spring Boot API)：支持接入企业级 Java 后端系统（http://localhost:8080/api），实现多用户实时协作。数据涵盖会议、议题、成员和活动四大模块。

2. 多维度视图管理 (Workspace Tabs)
   系统围绕会议生命周期划分为五大工作台：
   - 召开会议阶段 (Session View)：用于例会召开期间的实时记录。支持填写“常规报告”（行政进度等）以及添加、表决和处理“待议议程”。
   - 会后执行阶段 (Post-Meeting View)：呈现看板模式（Kanban），直观跟进各项议题的会后落实情况（如授权、执行中、已完成）。
   - 全局督办审查 (Supervision View)：提供跨会议的全局议题清单，方便管理员或负责人根据状态、优先级、负责人进行交叉筛选与催办。
   - 活动行事历 (Activity View)：新增的活动模块，用于记录和管理组织的线下/线上活动（时间、组织者、参与人等）。
   - 历届档案审查 (Archive View)：归档并展示所有历史会议及其关联的已完成议题。

3. 完备的议题生命周期 (Issue Lifecycle)
   每个议题 (Issue) 均包含详细的属性：
   - 基本信息：标题、流水号（如 20260720-01）、类别（所属部门，如微信编辑部等）、优先级（Low, Medium, High, Urgent）。
   - 状态流转：待议 (Agenda) -> 表决 (Voting) -> 通过 (Passed) / 驳回 (Rejected) -> 授权 (Authorization) -> 执行 (Execution) -> 完成 (Completed)。
   - 投票系统：支持简单多数 (Simple) 或绝对多数 (Absolute) 计票规则。
   - 执行落款：明确记录经办人和会商结论。

4. 导出与报告生成 (Export & Reporting)
   - 会议简报 (TXT 导出)：在会议阶段，一键生成当期例会回顾，包含常规报告与归档决议清单。
   - 高级排版导出 (PDF & LaTeX)：在档案视图中，可批量勾选历届会议，一键生成格式严谨的 PDF 文件，或导出标准的 LaTeX 源码，供学术或出版级别使用。

5. 界面与美学 (UI & Aesthetics)
   - 纯白起始页：大气优雅的入口界面与 Logo 展示。
   - 主题切换 (Theme Switcher)：内置四套精美配色 —— 黑白灰 (Classic)、普鲁士蓝 (Prussian)、勃艮第红 (Burgundy)、深夜护眼 (Late Night)。
   - 全局搜索 (Global Search)：支持通过关键词跨模块实时检索议题、会议及活动。
   - 实时钟表 (UTC Clock)：置顶显示当前北京时间及星期，增强会议的严肃性与时间观念。
