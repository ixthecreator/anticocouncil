Antico Council - 用户使用手册

第一章：系统概述

欢迎使用 安提柯议会 (Antico Council)。本系统是一款专为组织、编辑部、社团或企业设计的数字化会议与决议管理平台。系统采用极简的古典排版美学，结合现代化的工作流，支持议题的完整生命周期管理。

通过本系统，您可以轻松记录例会纪要、跟进决议执行情况、管理人员名单、记录重要活动，并随时导出标准的简报或公文级 PDF 及 LaTeX 源码。

第二章：数据存储与同步

在进入系统起始页或设置面板时，您可以选择适合您组织的数据存储模式：

  • 本地存储 (Local Storage)：默认模式，开箱即用。所有数据安全地保存在您当前浏览器的缓存中，适合单人使用或体验系统。
  • GitHub 同步模式：允许将数据以 JSON 格式自动绑定至您的 GitHub Repository 或 Gist，实现跨设备的云端版本控制与数据漫游。
  • Spring Boot 后端模式：企业级模式，支持接入 Java 后端系统（如 http://localhost:8080/api），实现多用户实时协作与并发修改。
提示： 您可以通过右上角的 导入/导出 JSON 按钮，随时在不同的存储模式或不同的设备之间迁移您的完整数据。

第三章：五大核心工作台

系统的核心功能划分为五个不同的标签页，覆盖了从会议召开到历史归档的完整流程。

1. 召开会议 (Session View)

这是会议进行时的主控制台。当您新建并进入一场会议时：

  • 常规报告区：用于记录会议的整体背景、各部门的工作汇报摘要。
  • 议题控制台：您可以添加新的“待议议程”。在会议中，您可以针对议题进行讨论记录，并执行“表决通过”或“直接授权”等操作。
  • 简报生成：会议结束后，点击“生成并导出 txt 简报”，系统会自动汇总所有报告及决议，生成一份标准的文本简报下载到本地。

2. 会后执行 (Post-Meeting View)

会议结束后，通过决议的议题将流转至此。这里采用 看板 (Kanban) 模式管理：

  • 状态列：清晰展示当前处于“授权分配”、“执行跟进”和“最终完成”的各项议题。
  • 拖拽或点击：您可以直接点击议题更改状态，或记录执行过程中的附加反馈信息。

3. 全局督办 (Supervision View)

管理员的全局控制塔。这里打破了单个会议的界限，汇集了所有仍在进行中的议题。

  • 交叉筛选：支持按“优先级”、“责任人(落款)”、“状态”及“所属部门”进行快速筛选。
  • 全局搜索：结合右上角的全局搜索框，可瞬间定位任何历史或当前的决议记录。

4. 活动行事历 (Activity View)

专门用于管理非会议性质的组织活动。

  • 记录结构：可记录活动名称、举办时间、主要组织者、参与人员以及具体的活动描述。
  • 支持按时间顺序排列，方便成员回顾组织的往期建设及事件。

5. 历届档案 (Archive View)

所有已结束的会议和已完成的议题的最终归宿。

  • 封存档案：已完成的议题可以通过点击“归档”按钮（或批量归档），永久进入档案库，确保执行界面的清爽。
  • 专业级排版导出：在此视图下，您可以勾选多场历史会议，点击 “编译 PDF 卷宗”，系统将利用前端的排版引擎，生成格式极其严谨、适合印刷或呈阅的学术级 PDF 报告。您也可以直接导出 LaTeX 源码 供进一步深度排版。

第四章：议题 (Issue) 的生命周期

本系统对议题的状态进行了严密的定义，反映了真实的行政议事规则：

状态节点 含义与适用场景
待议 (Agenda) 新提出的议案，尚未在会议上进行讨论。
表决 (Voting) 会议上正在讨论，需记录支持/反对票数（支持简单多数/绝对多数）。
通过 / 驳回 表决后的结论状态，被驳回的议题生命周期通常在此终止。
授权 (Authorization) 议题通过后，交由专人或部门，正在等待接收或下发正式指令。
执行 (Execution) 责任人已经开始实际处理该议题对应的工作。
完成 (Completed) 工作已确认完成。待其正式归档后，将移入历届档案。

第五章：系统实用工具

  • 全局搜索：位于页面右上角的放大镜图标，支持跨所有模块搜索关键词。
  • JSON 导入/导出：位于右上角的下载/上传图标，可以一键备份当前系统的所有会议、议题、成员和活动数据，或在更换浏览器时恢复数据。
  • 主题美化：点击右上角齿轮图标，可切换界面配色。系统提供四套精心调配的色彩：黑白灰经典 (Classic)、普鲁士蓝 (Prussian)、勃艮第红 (Burgundy)、深夜护眼 (Late Night)。
  • 人员管理：在会议管理面板左下角，可维护组织内的所有成员名单及其花名册。
